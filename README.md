# Supra Framework: Devnet

This branch holds the Move framework packages deployed at `0x1` on Devnet
(chain ID 50), generated from the on-chain package registry.
`registry.json` records the network's genesis hash, the genesis hashes it had
before earlier resets, the registry's SHA-256, and each package's upgrade
number and source digest.

See the README on the `main` branch for usage, tags and the generated files.
